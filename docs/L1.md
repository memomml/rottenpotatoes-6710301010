## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | Starter สำหรับรวบรวม dependencies ทั้งหมดที่จำเป็นสำหรับการทดสอบ เช่น JUnit, AssertJ, Mockito และ Spring Test ไว้ด้วยกันโดยจัดการเวอร์ชันให้อัตโนมัติผ่าน Spring Boot BOM |
| junit-jupiter | เฟรมเวิร์กหลักสำหรับเขียนและสั่งรัน unit test ใน Java (JUnit 5/6) ประกอบด้วย engine, annotations เช่น @Test และ assertions พื้นฐาน |
| assertj-core | ไลบรารีสำหรับเขียน assertion ด้วยรูปแบบ Fluent API ที่อ่านเข้าใจง่ายคล้ายประโยคภาษาอังกฤษ เช่น assertThat(actual).isEqualTo(expected) |
| mockito-core | ไลบรารีสำหรับสร้าง Mock objects และ Test Doubles เพื่อจำลองพฤติกรรม ช่วยแยกหน่วยโค้ดที่ต้องการทดสอบให้เป็นอิสระจาก dependencies ภายนอก |
| json-path | ไลบรารีสำหรับ parse และดึงข้อมูลออกจากโครงสร้าง JSON เพื่อตรวจสอบผลลัพธ์ในการทดสอบ |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
red bar แรกพิสูจน์ว่าชุดการทดสอบ (test case) ทำงานได้จริงและสามารถตรวจจับความผิดพลาดได้เมื่อโค้ดยังไม่ตอบสนองข้อกำหนด หากเห็นแต่ green bar อย่างเดียวจะไม่สามารถพิสูจน์ได้ว่าโค้ดผ่านเพราะ logic ถูกต้องจริง หรือผ่านเพราะ test มีข้อผิดพลาดจนไม่ตรวจอะไรเลย (false positive) การเริ่มจาก red bar จึงช่วยยืนยันความน่าเชื่อถือของ test ก่อนเริ่มลงมือเขียนโค้ดจริง

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
สามารถกู้งานทั้งหมดกลับมาได้จากรีโพซิตีบน GitHub (https://github.com/memomml/rottenpotatoes-6710301010) โดยใช้คำสั่ง git clone ลงเครื่องใหม่ และสิ่งที่ต้องทำเตรียมไว้ก่อนคือการ commit งานอย่างสม่ำเสมอพร้อมระบุข้อความ commit ที่สื่อความหมาย และ push ขึ้นไปยัง remote repository บน GitHub ทุกครั้งที่งานในแต่ละขั้นตอนเสร็จสิ้น
